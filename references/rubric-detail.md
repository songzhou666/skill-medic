## 每维详细说明

### 1. 触发契约（15 分）
- description 同时含"做什么 + 何时调用 + 何时不调用"
- 用词具体非空话，参考 ClaudSkills 描述深度 ≥ 200 字符
- 扣分：description < 40 字；只有能力罗列无触发条件；无反触发词

### 2. 流程机制（15 分）
- 正文为有序 Phase/Step 节点，每节点有输入/产出/禁止跳步
- 有分支判断逻辑
- 扣分：大段人设形容词；无编号步骤；单一路径无分支

### 3. 异常与熔断（12 分）
- 缺信息→停止并追问，禁止编造
- 失败有 fallback 路径
- 有最大迭代轮次限制
- 扣分：缺材料直接脑补；无任何失败处理说明

### 4. 产出控制（13 分）
- 有中间产物（非一步输出最终大文档）
- 交付前逐条 checklist 自检
- 输出有验收标准
- 扣分：执行完直接输出结束，无自检步骤

### 5. 边界与上下文（12 分）
- 明确可读范围/上限阈值/超限拒绝
- 有分层加载（chunk/渐进式披露）
- 扣分：无任何边界；单文件超长；重复通用常识堆砌

### 6. 内容价值密度（13 分）
- 核心是业务方法论与判断规则
- 有反模式说明
- 示例真实
- 扣分：只有输出模板；常识性内容占大头；示例是占位符

### 7. 工程配套（10 分）
- 有可执行工具层/脚本、配置、README、版本、测试或自检手段
- 判定原则：功能不涉及数据/外部工具时纯提示词不扣分；功能需要数据处理或外部工具却无工具层 → 该维直接 0 分

### 8. 维护健康度（10 分）
- 有 CHANGELOG/版本号
- 有更新或修复痕迹
- README 与实现一致
- 扣分：只有 zip 备份无活动目录；README 与 SKILL.md 不一致
